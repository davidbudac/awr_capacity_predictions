Alert lifecycle · cap_results.refresh

    
One alert, five runs

    

      

      
run 1
NEW
WARN
inside dtf_warn (90 days)

      
run 2
ESCALATED
WARN → CRIT
inside dtf_crit (30); clears an ack

      
run 3
missed 1
still OPEN
space added, alert gone

      
run 4
RESOLVED
closed
missing 2 runs = resolve_grace_runs

      
run 5
REOPENED
WARN
same state_key is back

    

    
cap_results.ack silences an alert until it escalates or reopens. Pollable views: CAPR_ALERTS_LATEST, CAPR_ALERT_EVENTS.
